# Baselines

Nothing from these projects is copied here. Each folder records the upstream
repository, the commit used, and the wrapper or patch files written for this
benchmark. Clone upstream at that commit, then apply `patch.diff` and copy
`wrappers/` over the clone. Weights come from each project under its own license.
